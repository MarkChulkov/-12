# Book Tracker - Трекер прочитанных книг

**Автор:** Иван Иванов (замените на своё имя)

## Описание программы
GUI-приложение для учёта прочитанных книг. Позволяет добавлять книги с указанием названия, автора, жанра и количества страниц, фильтровать по жанру и минимальному количеству страниц, сохранять данные в JSON-файл.

## Инструкция по запуску
1. Убедитесь, что установлен Python 3.6 или выше.
2. Сохраните файл `book_tracker.py` в любую папку.
3. Запустите программу командой:
   ```bash
   python book_tracker.py
Для работы не требуется установка дополнительных библиотек (используется только встроенный модуль tkinter).

Примеры использования
Пример 1: Добавление книги
Введите: Название = "Война и мир", Автор = "Толстой", Жанр = "Роман", Страниц = "1300"

Нажмите "Добавить книгу"

Книга появится в таблице

Пример 2: Фильтрация
Чтобы показать книги жанра "Фантастика", введите "Фантастика" в поле фильтра "Жанр" и нажмите "Применить фильтр"

Чтобы показать книги с количеством страниц больше 300, введите "300" в поле "Страниц >"

Пример 3: Проверка валидации
Попробуйте добавить книгу с пустым полем → появится ошибка

Попробуйте ввести буквы в поле "Страниц" → появится ошибка

Тестирование (для проверки)
Добавьте 3-4 книги с разными жанрами и страницами

Закройте программу и откройте снова → данные сохранятся

Примените фильтр по жанру → отобразятся только нужные книги

Нажмите "Сбросить фильтр" → вернутся все книги
